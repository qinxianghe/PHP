# PHP Basics

Small historical snippets exploring PHP weak typing, variables, assignment, and command invocation.

| File | Focus |
| --- | --- |
| `examples/weak_typing.php` | Type conversion and mixed variable values |
| `examples/variables_and_commands.php` | Variable handling and a shell-command example |
| `examples/variable_assignment.php` | Variable assignment and output |

These are learning snippets. Inspect them before execution; the command example calls `system()`. They are not deployed and should not be treated as a web application or secure request-handling examples.

PHP is not installed as part of the Mac setup. The cleanup preserves the original bytes and checks file navigation only. See [source mapping](docs/catalog.md) and [validation](docs/validation.md).
